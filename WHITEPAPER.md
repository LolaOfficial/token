## Technical Architecture

### Smart Contracts
Lola token utilizes two main smart contracts:

1. **JettonMinter Contract:**
   - Manages token minting
   - Handles admin operations
   - Stores token metadata
   - Implements TEP-74 standard

2. **JettonWallet Contract:**
   - Manages individual token balances
   - Handles transfers
   - Implements burn functionality
   - Implements TEP-89 standard
